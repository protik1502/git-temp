# HONOR — Remember. Support. Empower.

A premium frontend-only web-development prototype for the problem statement:
**War Veterans And Defense Martyr Families Welfare Support Fund**

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- CSS Grid / Flexbox / Media Queries
- LocalStorage
- Browser Print API

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Features
- Responsive premium UI
- Causes and cause details
- Simulated one-time/monthly donation flow
- Dynamic demo receipt + print
- Honor Wall using LocalStorage
- Veteran entrepreneurship showcase with search/filter
- Impact dashboard
- Transparency page
- About / mission
- Mobile navigation

## Important
This is a frontend college prototype. It does **not** process real money, issue legally valid tax certificates, or provide real payment security. A production system would require a compliant backend, payment gateway, authentication, database, security controls and verified financial/tax workflows.
